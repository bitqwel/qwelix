# qwelix
Qwelix – QR Tools
Make QR codes the quick way.
Features
🔗 Link to QR: turn any website or profile link into a QR code.
💸 UPI Payment QR: add a UPI ID, payee name and an optional amount, so people can pay in one scan.
🎲 Random share link: every QR gets its own link you can copy and send.
🔒 Private: your links and payment details never leave your device.
🪟 Modern design: glass-style interface with smooth animations, in dark and light.
🆓 Free and open source: no ads, no account, MIT license.
More tools are coming soon.
